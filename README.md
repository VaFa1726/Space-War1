# Space War 🚀
A classic 2D space shooter game built for Windows desktops using C# and Windows Forms.

## Features
- **Windows Forms UI**: Fully native Windows desktop game.
- **Multiple Screens**: Handles different game states using multiple Forms (Menu, Game, Game Over, etc.).
- **Simple Mechanics**: Classic arcade-style space shooting gameplay.

## Requirements
- Visual Studio / .NET Framework
- Windows OS

## How to Play
Open the `.sln` or `.csproj` file in Visual Studio, build the project, and run the executable.
