## 📌 Overview
Space War is a 2D desktop game developed using C# and Windows Forms. It brings back the classic arcade space shooting experience right to your Windows machine.

## ✨ Features
- **Windows Forms UI**: Fully native Windows desktop application.
- **Multiple Game Screens**: Handles different game states using multiple Forms (Menu, Main Game, Game Over, etc.).
- **Arcade Mechanics**: Classic space shooting gameplay with simple controls.

## 🛠️ Requirements
- Visual Studio
- .NET Framework
- Windows OS

## 🚀 How to Play
1. Clone the repository to your local machine.
2. Open the `.sln` or `.csproj` file in **Visual Studio**.
3. Build the project.
4. Press `F5` or click **Start** to run the game executable.
